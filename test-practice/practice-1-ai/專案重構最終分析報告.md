## 🛠️ 1. 已確認完善的核心功能清單

### 前台功能

- [index.php](index.php) 已重構為 Bootstrap 5 響應式首頁。
- 頂端 Header 會動態讀取 `titles` 資料表的 `title` 與 `image`。

  ```text

  ```

- 寵物列表會依照 `posts.menu_id` 撈取對應案件。
- 寵物卡片會顯示：
  - 寵物名字 `pet_name`
  - 特徵描述 `features`
  - 聯絡電話 `phone`
  - 案件狀態 `case_status`
  - 寵物圖片 `image`

- 寵物卡片可連結至 `detail.php?id=案件編號`。
- `detail.php` 會完整顯示寵物照片、名字、狀態、特徵與聯絡電話。

### 後台功能

- [admin.php](admin.php) 已加入登入 Session 防護。
- 未登入時會立即導向 `login.php` 並停止後續程式執行：

  ```php
  if (($_SESSION['login'] ?? 0) !== 1) {
      to('login.php');
      exit;
  }
  ```

- 後台 `do` 路由採用白名單限制，避免任意載入未授權檔案。
- 後台提供以下管理項目：
  - 網站招牌
  - 守護標語
  - 宣導輪播
  - 寵物照片
  - 瀏覽人次
  - 頁尾設定
  - 寵物案件
  - 管理員帳號
  - 選單管理
- `back/` 管理頁面與資料變更 API 均具備登入檢查。

### 登入安全

- [login.php](login.php) 使用 Bootstrap 5 登入卡片。
- 表單會送至 `api/api_login.php`。
- 登入成功後會設定：
  - `$_SESSION['login']`
  - `$_SESSION['username']`
- 登入成功後使用 `session_regenerate_id(true)`，降低 Session Fixation 風險。
- 登入失敗會回到 `login.php`，不再導向不存在的舊 `do=admin` 路由。
- 登出會清除登入 Session 並返回登入頁面。

### 資料庫動態對接

- [api/db.php](api/db.php) 的資料表物件已與目前 SQL 對齊：

  ```php
  $Post = new DB('posts');
  $Title = new DB('titles');
  $Menu = new DB('menus');
  $Banner = new DB('banners');
  ```

- `titles` 使用目前欄位：`id`、`title`、`image`、`status`、`deleted_at`。
- `posts` 使用目前寵物欄位：`menu_id`、`pet_name`、`features`、`phone`、`image`、`case_status`、`status`、`sort`、`deleted_at`。
- `a2s()` 的 NULL 條件已使用正確 SQL 語法：

  ```sql
  `sort` IS NULL
  `deleted_at` IS NULL
  ```

- `back/title.php` 與 `back/post.php` 已排除軟刪除資料。

## ⚠️ 4. 本地端手動測試溫馨提示

以下項目涉及瀏覽器、Session、資料庫與檔案系統，建議在本機逐項測試：

### 前台測試

1. 開啟 `index.php`，確認頂端長條招牌圖片正常顯示。
2. 確認中央 Banner 會自動輪播。
3. 點擊左右箭頭，確認 Carousel 可手動切換。
4. 點擊「寵物認養 → 貓咪認養」，確認網址包含：

   ```text
   ?menu_id=4
   ```

5. 確認列表只顯示對應 `menu_id=4` 的案件。
6. 測試不存在的分類或沒有資料的分類，確認畫面顯示空資料提示而不是 PHP 錯誤。
7. 點擊任一寵物卡片，確認能開啟 `detail.php?id=...`。
8. 確認詳細頁的電話、特徵、照片與案件狀態都正常顯示。
9. 使用手機寬度測試導覽列折疊、卡片排列與圖片比例。

### 登入與 Session 測試

1. 未登入時直接開啟：

   ```text
   admin.php
   ```

   應自動跳轉至 `login.php`，不可看到後台側欄或 `Forbidden` 畫面。

2. 未登入時直接開啟後台管理頁，例如：

   ```text
   admin.php?do=title
   ```

   應同樣被導向登入頁。

3. 使用錯誤帳號密碼登入，確認會回到登入頁。
4. 使用正確帳密登入，確認可進入後台 Dashboard。
5. 點擊登出後，再按瀏覽器上一頁或直接輸入 `admin.php`，確認無法繼續使用後台。
6. 未登入時直接 POST 到後台 API，確認回應為拒絕而不是成功修改資料。

### 後台 CRUD 測試

1. 開啟「網站招牌管理」，確認 `titles` 資料完整顯示。
2. 修改網站標題文字並按下儲存，回到前台確認 Header 同步更新。
3. 更換招牌圖片，確認檔案實際寫入：

   ```text
   upload/
   ```

4. 開啟「寵物案件管理」，確認 `posts` 案件可正常讀取。
5. 新增寵物案件，確認：
   - 圖片成功上傳至 `upload/`
   - 資料庫儲存的是檔案名稱字串
   - 前台 `<img src="upload/檔案名稱">` 能正常顯示
6. 修改寵物名字、特徵、電話與案件狀態，確認前台同步更新。
7. 測試刪除案件，確認 `deleted_at` 後不再出現在前台。
8. 在選單管理中測試：
   - 修改既有次選單
   - 刪除既有次選單
   - 新增多筆次選單
   - 取消動態新增列
9. 測試 Banner、寵物照片與守護標語的新增、修改、刪除功能。

- 目前 PHP CLI 顯示的 OpenSSL 重複載入警告屬於本機 PHP 設定問題，不是專案語法錯誤。
